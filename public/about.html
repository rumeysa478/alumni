About This Project

🎓 Alumni Tracking System

A web platform designed to organize, search, and manage alumni profiles, career milestones, and networking.

🎯 Purpose & Core Capabilities

This project is developed as part of the 3rd Year Web Programming Course to establish an institutional alumni community:

  • Profile Management: Storing graduation year, department, contact details, and career history.
  • Search & Filter: Quickly discovering alumni by graduation year, field of study, or current company.
  • Job & Opportunity Board: Enabling graduates and verified partners to share career opportunities.

💻 Tech Stack & Architecture

  • Frontend (JavaScript): Responsive UI, dynamic DOM manipulation, and asynchronous API calls.
  • Backend (Node.js & Express): RESTful API architecture, request validation, and routing.
  • Database (PostgreSQL): Relational database providing schema integrity, ACID compliance, and relationships.
  • Containerization (Docker & Docker Compose): Reproducible, isolated development and production environments.
  • Version Control (Git & GitHub): Structured branch workflows, peer code reviews, and automated CI/CD.
